# MY COOL README

This README explains how to run my code. It should be straightforward.

## Setup

1. Connect to the Raspberry Pi.
2. Install what you need.
3. Run the generator.

That’s it.

## Connect to the Pi

SSH into the Raspberry Pi and go to the lab folder:

```bash
ssh raspberrypi
cd lab01
```

If that doesn’t work, try again or search your issue online.

## Install dependencies

Create a virtual environment and install requirements:

```bash
python -m venv venv
pip install (see my imports for the libraries needed)
```

Now you’re ready.

## Run

Run the program:

```bash
python event_generator.py 
```

It will generate events. You can check the file.

## Notes

- If you get errors, update Python.
- The program should work for everyone.
- Make sure you have internet.
